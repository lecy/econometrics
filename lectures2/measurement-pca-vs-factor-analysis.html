Purpose

Principal component analysis (PCA) and factor analysis (FA) are often confused, and in practice they are sometimes used interchangeably. Both take a large set of correlated variables and return a few dimensions with loadings and scores. But they rest on different models of where the data come from. This walkthrough:

  1. Explains the conceptual and statistical difference between FA and PCA.
  2. Explains what psych::principal() is actually doing.
  3. Fits a four-dimension solution both ways on the same census data and compares the loadings, the variance explained, and the scores.

It builds on the Factor Analysis walkthrough, which uses the same data and explains how the four-factor solution was chosen.

1. Two different questions

Factor analysis

Question: What latent constructs could be generating these observed variables?

FA is a measurement model. Each observed variable is treated as an imperfect indicator of a smaller set of latent factors, plus error:

\[ X = \Lambda F + \epsilon \]

  • \(\Lambda\): loadings, how strongly each variable reflects each factor
  • \(\epsilon\): uniqueness, the variance not explained by the factors, including measurement error

FA models only the shared (common) variance and sets the unique variance aside.

Principal component analysis

Question: How can we re-express the data with fewer variables while keeping as much of the variance as possible?

PCA is a data compression method, a rotation of the coordinate system. Each component is a weighted sum of the observed variables, chosen to capture as much variance as possible:

\[ C = W X \]

The arrows run the other way. In FA, the factors cause the variables. In PCA, the components are built from the variables. PCA does not model:

  • latent causes
  • measurement error
  • the split between common and unique variance

One-line intuition. FA tries to explain the covariance among variables. PCA tries to preserve their total variance.

2. Common versus total variance

Factor analysis PCA
Models latent variables Yes No
Separates common from unique variance Yes No
Includes an error term Yes No
Treats all variance as signal No Yes
Built for theory and construct measurement Yes Sometimes
Built for compression and prediction features Sometimes Yes

The practical implication: PCA loadings usually look stronger than FA loadings. PCA counts all of a variable’s variance, including the noise, as something to explain. FA loadings reflect only the variance a variable shares with the others.

What loadings and scores mean

Loadings

  • FA loading: how strongly does this variable measure the latent factor?
  • PCA loading: how strongly does this variable contribute to the component?

Scores

  • FA factor scores: estimates of each case’s value on the latent trait. They are model-based, and they contain estimation error.
  • PCA component scores: exact projections of each case onto the component axes. They are geometry, not estimates.

Rotation, such as varimax, makes both solutions easier to read, but rotating PCA does not turn it into FA.

3. What psych::principal() is doing

A common snippet looks like this:

pc4 <- principal(d, nfactors = 4, rotate = "varimax", scores = TRUE)
print.psych(pc4, cut = 0.3, sort = TRUE)

This is PCA, even though the argument is named nfactors. psych::principal() extracts principal components, optionally rotates them, and returns component scores. The psych package uses the same argument names for both methods so the output is easy to compare, which is also why the two are easy to confuse.

5. Fit PCA and FA with four dimensions

Both use varimax rotation, so each solution has uncorrelated dimensions and is as easy to read as possible.

PCA with psych::principal()

pca4 <- psych::principal(
  X_z,
  nfactors = 4,           # number of components to keep
  rotate   = "varimax",   # orthogonal rotation
  scores   = TRUE         # return component scores
)

FA with psych::fa()

Principal axis factoring (fm = "pa") models only the common variance. As explained in the Factor Analysis walkthrough, this four-factor solution produces a Heywood-case warning, because two pairs of variables are near-duplicates. It is suppressed here.

fa4 <- suppressWarnings(psych::fa(
  X_z,
  nfactors = 4,
  fm       = "pa",          # principal axis factoring
  rotate   = "varimax",
  scores   = "regression"   # regression-method factor scores
))

6. Line up the dimensions

Neither method guarantees that its first dimension matches the other method’s first dimension. PCA names its rotated components RC1–RC4 and FA names its factors PA1–PA4, and the numbering doesn’t correspond. Before comparing, match each factor to the component whose scores correlate with it most strongly, and flip the sign if needed. The sign of a loading column is arbitrary in both methods.

cross <- cor(fa4$scores, pca4$scores)
round(cross, 2)
##       RC1  RC4   RC2   RC3
## PA1  0.98 0.04  0.00 -0.02
## PA2 -0.01 0.95 -0.04 -0.01
## PA4  0.00 0.01  0.92  0.00
## PA3  0.00 0.02 -0.02  0.89
# For each FA factor, the PCA component it matches best
match_pc <- colnames(cross)[apply(abs(cross), 1, which.max)]
names(match_pc) <- rownames(cross)
stopifnot(!anyDuplicated(match_pc))
match_sign <- sign(cross[cbind(rownames(cross), match_pc)])
names(match_sign) <- rownames(cross)

# Construct names from the Factor Analysis walkthrough
factor_names <- c(PA1 = "ses", PA2 = "stability", PA4 = "immigrant", PA3 = "aging")
fa_order <- names(factor_names)

tibble(
  construct = factor_names[fa_order],
  fa_factor = fa_order,
  pca_component = match_pc[fa_order],
  score_correlation = round(cross[cbind(fa_order, match_pc[fa_order])], 3)
)

The pca_minus_fa column compares the size of the two loadings, ignoring sign. Two patterns stand out:

  • Strong indicators barely change. College degrees, income, and homeownership load within about 0.03 of each other under both methods. When most of a variable’s variance is shared, there is little unique variance for the two methods to disagree about.
  • Weaker indicators load higher in PCA. Female labor force participation, children, and vacant units on the aging dimension, and percent Black on the stability dimension, gain roughly 0.08 to 0.12 under PCA. FA sets much of their variance aside as unique; PCA counts it. This is the common-versus-total-variance difference in action.

The main exceptions run the other way: percent speaking another language and percent 60 and older load higher in FA. These are the near-duplicate variables behind the Heywood warning, where FA treats essentially all of the variance as shared.

8. Variance explained and communalities

Both methods report a communality (\(h^2\)) for each variable: the share of its variance captured by the four dimensions. In FA, the rest is uniqueness. In PCA, the rest is simply variance the four components left behind.

9. Compare the scores

Three things to notice:

  • PCA component scores are exactly uncorrelated. They are exact projections onto orthogonal axes.
  • FA factor scores are only approximately uncorrelated. The factors are orthogonal, but the scores are estimates of them, and estimation error introduces small correlations.
  • The matched scores are highly correlated across methods (roughly 0.9 or higher). For a large, well-structured set of variables, the two methods agree on which dimensions exist. They disagree about how much of each variable is signal.

10. When to use which

Prefer factor analysis when

  • You want interpretable latent constructs that you can name and defend
  • You care about measurement validity, meaning the split between common and unique variance
  • You treat the variables as indicators of underlying neighborhood conditions

Prefer PCA when

  • You want compact features for prediction or dimension reduction
  • You want to keep as much of the total variance as possible in fewer dimensions
  • You don’t need a latent-variable or measurement interpretation

A practical workflow

Many projects:

  1. Run PCA as a quick check of the structure.
  2. Run FA to interpret and report the constructs.
  3. Use FA factor scores, or PCA components, as predictors in later models.
