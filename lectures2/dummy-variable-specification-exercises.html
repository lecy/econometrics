Section one

How to use this handout

The conventions, the four-step routine, and the one rule that answers most of the questions.

Before you start

Every picture is a set of conditional means.

Points and lines stand for group means or conditional means, not fitted estimates with standard errors. The picture suggests a contrast; it does not establish statistical significance or causality. A real test needs case-level data and a standard error appropriate to the design. The numbers are illustrative.

Four steps for every question.

  1. Define the indicators and name the reference (omitted) group.
  2. Write the regression equation. Assume an error term in every model.
  3. State the null hypothesis as a restriction on a coefficient, such as β2 = 0.
  4. Interpret each relevant coefficient as a specific difference between two points in the picture.

The one rule behind almost every answer.

Software tests every coefficient against zero. A coefficient on a dummy is the gap between that category and the omitted category, measured where every other predictor equals zero. So if you want a contrast tested for you, choose two things:

  • the reference category, so the comparison is against the group you care about; and
  • the zero point of any continuous variable (by centering), so the gap is measured where you care about it: a cutoff, an intervention date, a benchmark.

How to get coefficients from a picture.

Write the equation once for each cell, setting each dummy to its 0/1 value. The reference cell gives you the intercept. Every other cell adds exactly one new coefficient, so you can solve for each one by subtraction.

Coding conventions.

  • Every indicator is written dname and equals 1 when the name is true.
  • The column headed 1 is the intercept. Y is the illustrated cell mean unless stated otherwise.
  • Design matrices often display complementary indicators side by side (for example dtreat and dcontrol) so you can see both reference choices. Never enter a complete set of complementary indicators together with an intercept. Columns left out of the model are shown in grey.
  • Rows are observation types. Real data would have many rows of each type, which is where the standard errors come from.

Work the questions before reading the solutions.

Each solution repeats the figure and question, then gives a short answer, the reasoning, a design matrix, the model, a coefficient table, and a common mistake.

1A. One sample versus a benchmark

A sample has mean 74; a historical benchmark is 70. Construct an intercept-only regression that tests whether the population mean equals 70. What does its intercept measure? Would a group dummy help?

Short answer

Subtract the benchmark from the outcome, Yc = Y − 70, and regress it on a constant alone. The intercept is the sample mean minus the benchmark (74 − 70 = 4), and testing β0 = 0 is exactly the one-sample t-test of μ = 70. A group dummy cannot help: there is only one group, so the dummy would be a column of ones that duplicates the intercept.

Why this works

A regression with nothing but a constant estimates the mean of the outcome, and its standard error is s/√n, the same standard error the one-sample t-test uses. The only problem is that software tests the intercept against zero, and nobody doubts that the mean score is above zero. Shifting the outcome by 70 moves the benchmark to zero, so the default test becomes the test you want.

An equivalent route is to regress raw Y on a constant (β0 = 74) and ask for the linear-hypothesis test β0 = 70. The t-statistic is identical. Recentering simply makes the right test the default one.

  • Regressing raw Y on a constant and reading the default p-value. That tests whether the mean is zero, not whether it is 70.

1B. Two independent samples

Independent control and treatment groups have means 50 and 62. Code one dummy so its coefficient tests their difference. What changes if treatment is omitted instead?

Short answer

Use Y = β0 + β1dtreat + ε. The intercept is the control mean (50) and β1 = 12 is treatment minus control, so testing β1 = 0 is the two-sample t-test. Omitting treatment instead gives (62, −12): the same test, the same |t|, with the sign reversed.

Why this works

With one dummy and a constant, the constant takes care of the omitted group and the dummy measures how far the other group sits from it. Write the equation for each row:

  • Control (dtreat = 0): Y = β0 = 50
  • Treatment (dtreat = 1): Y = β0 + β1 = 62, so β1 = 12

Ordinary OLS standard errors pool the two groups’ variances, so this matches the equal-variance (Student) t-test. For the Welch test, ask for heteroskedasticity-robust standard errors.

1C. Paired samples

The same people A, B, and C are measured before and after a program. Construct (a) a regression on within-person differences, (b) a long-format model with dA, dB, dC and dpost, and (c) the equivalent model with a person-specific intercept αi. Why does treating the two periods as independent samples give a different standard error?

Short answer

All three models estimate the same thing: the average within-person change, (8 + 6 + 7)/3 = 7, with the same standard error. The independent-samples version gets the same 7 but a much larger standard error, because it leaves the stable differences between people in the error term. Pairing makes each person their own control.

(a) Difference-score regression

Compute each person’s change, ΔA = 8, ΔB = 6, ΔC = 7, and regress it on a constant:

Δi = γ0 + ui,  γ̂0 = 7

This is 1A again, applied to the differences. Testing γ0 = 0 is the paired t-test.

(b) Long format with ID dummies

Yit = αAdA + αBdB + αCdC + βdpost + εit

There is no common intercept: all three ID dummies are included, and together they do the intercept’s job. Each person gets their own baseline, and β̂ = 7 is the common within-person change.

Why are the fitted intercepts 50.5, 59.5, 55 rather than the observed pre scores 50, 60, 55? The model forces everyone to share one change of 7, but the actual changes are 8, 6, and 7. Each α̂i therefore lands at the person’s own average minus half the common change. For A, 54 − 3.5 = 50.5. The leftover ±0.5 residuals are the only error the model sees.

(c) Person-specific intercepts

Yit = αi + βdpost + εit,  i ∈ {A, B, C}

This is the same model as (b) in shorter notation. αi stands for the three ID columns; it is not a single common intercept. This is the one-way fixed-effects model you will see again in panel data.

Why the standard errors differ

People differ a lot in level (pre scores of 50, 60, 55) but very little in change (8, 6, 7). The independent-samples test compares the two columns of scores, so all of that level variation counts as noise. The paired test compares each person with themselves, so it disappears.

2. Three categories, two reference choices

Means are Traditional 70, Hybrid 76, Online 61. Model A should test Hybrid versus Traditional and Online versus Traditional directly. Model B should test Traditional versus Online and Hybrid versus Online directly. Specify both and calculate the coefficients.

Short answer

Omit the category that every requested contrast shares. Model A omits Traditional and gives (70, 6, −9). Model B omits Online and gives (61, 9, 15). The two models fit the data identically; they just put p-values on different comparisons.

Why this works

Three groups allow three pairwise comparisons, but a model with an intercept has room for only two dummy coefficients. Whichever category you omit becomes the comparison point for both of them. The third comparison is still available as a difference of coefficients, but it needs a separate linear-combination test. In Model A, Hybrid versus Online is β1 − β2 = 6 − (−9) = 15, which Model B reports directly as γ2.

  • Model A, Traditional row: β0 = 70. Hybrid: 70 + β1 = 76. Online: 70 + β2 = 61.
  • Model B, Online row: γ0 = 61. Traditional: 61 + γ1 = 70. Hybrid: 61 + γ2 = 76.

3. Parallel lines: a common slope

Group A follows 20 + 3X and B follows 30 + 3X. Make the slope and the group gap individual coefficient tests. What restriction on the slopes have you imposed?

Short answer

Y = β0 + β1X + β2dB + ε gives (20, 3, 10). β1 is the common slope and β2 is the vertical gap between the lines. You have imposed equal slopes, not tested them: with no X·dB term, the model cannot draw anything but parallel lines.

Why this works

Write the line for each group:

  • A (dB = 0): Y = β0 + β1X
  • B (dB = 1): Y = (β0 + β2) + β1X

A dummy on its own moves a line up or down. It cannot tilt it. Because both lines share β1, the gap β2 = 10 is the same at every value of X. That is the one situation in which “the group difference” has a single answer. To check whether the lines really are parallel, add the interaction and test it (exercise 4).

4. Nonparallel lines: intercept and slope interactions

A follows 20 + 2X and B follows 30 + 5X. Embed tests for the intercept difference, the slope difference, and A’s slope. Then recode so B’s slope is a single coefficient.

Short answer

Y = β0 + β1X + β2dB + β3(X·dB) + ε gives (20, 2, 10, 3): A’s slope, the intercept gap, and the slope gap are each one coefficient. B’s slope is β1 + β3 = 5, a sum. To make it a single coefficient, make B the reference by using dA and X·dA instead. Then γ1 = 5.

Why this works

Write each group’s line and match it to the picture:

  • A: Y = β0 + β1X = 20 + 2X
  • B: Y = (β0 + β2) + (β1 + β3)X = 30 + 5X

The main-effect dummy shifts the intercept and the interaction shifts the slope. Every coefficient describes the reference group (A) or B’s difference from it. In particular, β1 is not “the effect of X”; it is the effect of X for A.

Also note what the intercept gap means now. β2 = 10 is the gap at X = 0 only. At X = 5 the gap is 10 + 3·5 = 25. If X = 0 is outside your data or not meaningful, center X at a value you care about, and β2 becomes the gap there.

5. A 2 × 2 program-by-setting design

Control means are 40 (low resource) and 60 (high); program means are 55 and 60. Test the program effect in low settings, its effect in high settings, and whether the effects differ. Which reference choice makes the high-setting effect a single coefficient?

Short answer

With low settings as the reference (use dhigh), the model gives (40, 15, 20, −15). The program effect in low settings is β1 = 15, the difference in effects is β3 = −15, and the high-setting effect is the sum β1 + β3 = 0. To test the high-setting effect as one coefficient, make high the reference by using dlow. Then γ1 = 0.

Why this works

The key idea: a main effect in an interacted model is the effect where the other dummy equals zero, which is in the reference category of the other factor. So the program coefficient is the program effect in whichever setting you omitted.

  • Control, low: β0 = 40
  • Program, low: β0 + β1 = 55 → β1 = 15
  • Control, high: β0 + β2 = 60 → β2 = 20
  • Program, high: β0 + β1 + β2 + β3 = 60 → β3 = −15

The interaction is the gap between what you’d expect if program and setting simply added up (40 + 15 + 20 = 75) and what you actually see (60). Here the program closes the resource gap in low settings and does nothing where resources are already high. The interaction test is the same in both codings; only its sign flips.

6. Pre/post with a comparison group

Control changes from 50 to 55; treatment changes from 50 to 70. Test the baseline group difference, the control group’s time change, and the difference in changes. Which coefficient is the last contrast?

Short answer

With control/pre as the reference, Y = β0 + β1dtreat + β2dpost + β3(dtreatdpost) + ε gives (50, 0, 5, 15). β1 is the baseline gap, β2 is the control group’s change, and the interaction β3 is the difference in changes. This is the difference-in-differences estimator.

Why this works

This is exercise 5 with “setting” replaced by “time.” Solve cell by cell:

  • Control, pre: β0 = 50
  • Treatment, pre: β0 + β1 = 50 → β1 = 0
  • Control, post: β0 + β2 = 55 → β2 = 5
  • Treatment, post: β0 + β1 + β2 + β3 = 70 → β3 = 15

So β3 = (70 − 50) − (55 − 50) = 20 − 5 = 15. The control group’s change (5) is the counterfactual: what would have happened to the treatment group without the program. β0 + β1 + β2 = 55 is the treatment group’s expected post score under that counterfactual, and β3 is how far the observed 70 sits above it. Reading β3 as a program effect requires the parallel-trends assumption: without the program, both groups would have changed by the same amount.

Changing the reference changes what the main effects mean. Flipping one reference (group or period) flips the sign of the interaction; flipping both leaves it unchanged.

7. Cumulative doses

Mean outcomes after zero, one, and two doses are 20, 25, and 30. Build cumulative indicators so each coefficient is the increment from receiving another dose. Compare this with indicators for exactly one and exactly two doses.

Short answer

Define ddose1 = 1 if a person received at least one dose and ddose2 = 1 if they received at least two. The model gives (20, 5, 5): β1 is the gain from the first dose and β2 is the additional gain from the second. Exact-group indicators give (20, 5, 10) instead, comparing each group with zero doses.

Why this works

A two-dose person has both cumulative indicators switched on, so their predicted mean is β0 + β1 + β2. A one-dose person has β0 + β1. The difference between them is β2 alone, the step from one dose to two.

With exact-group indicators, a two-dose person has only dtwo switched on, so α2 is the whole distance from zero doses. The second increment is still there, but only as α2 − α1 = 5.

Both codings fit the same three means; they differ only in which contrasts get a p-value. Cumulative coding also lets you test whether each dose adds the same amount (β1 = β2). That is exactly the assumption a linear dose term β·doses would impose without testing. The same stacking idea reappears in exercises 8 and 12, where a post-period dummy is added on top of a trend.

8. Interrupted time series

Time is centered so the first post-intervention period is t = 0. The pretrend slope is 2. At t = 0 the post line is 10 above the extrapolated pre line, and then it rises 5 per period. Specify separate tests for the immediate level change and the slope change. What if the graph has a kink but no jump?

Short answer

Y = β0 + β1t + β2dpost + β3tafter + ε, with tafter = t·dpost, gives (20, 2, 10, 3). β2 is the immediate jump, β3 is the change in slope, and the post slope is β1 + β3 = 5. A kink with no jump means β2 = 0. You can test that, or impose it by dropping dpost.

Why this works

This is exercise 4 with time as X and before/after as the groups:

  • Before: Y = β0 + β1t = 20 + 2t
  • After: Y = (β0 + β2) + (β1 + β3)t = 30 + 5t

Because tafter = 0 at the first post period, the two lines differ by exactly β2 at t = 0. That is the gap between the observed post level (30) and where the old trend would have been (20). Centering time at the interruption is what makes the dummy coefficient mean “jump at the interruption.” Note that β0 = 20 is not an observed point; it is the pre-trend extrapolated to t = 0, the counterfactual level.

Common mistakes
  • Using only dpost to test a slope change. A dummy on its own gives a jump with parallel lines.
  • Starting the post-period counter at 1. If tafter = 1 in the first post period, the post line becomes (β0 + β2 + β3) + (β1 + β3)t. The jump at t = 0 is then β2 + β3, and β2 alone (here 7, not 10) is a gap one period before the interruption.
  • Adding dpre alongside dpost and the intercept. Use one or the other.

9. Regression discontinuity at a cutoff

An eligibility rule switches on at running-variable value X = 50. The expected outcome jumps by 10 at the cutoff, and the two local slopes differ. Code the running variable and threshold dummy so the jump is one coefficient. Why center at 50?

Short answer

Let xc = X − 50 and dabove = I(X ≥ 50). Then Y = β0 + β1xc + β2dabove + β3(xcdabove) + ε gives (40, 2, 10, 2), and β2 is the jump at the cutoff. Center at 50 because, in a model with an interaction, the dummy measures the gap where the running variable equals zero. Centering puts zero at the cutoff.

Why this works

This is exercise 8 again, with the running variable in place of time:

  • Below: Y = β0 + β1xc = 40 + 2xc
  • Above: Y = (β0 + β2) + (β1 + β3)xc = 50 + 4xc

At the cutoff, xc = 0 and the lines differ by β2. The value 40 is a left-hand limit: where the untreated line would arrive at the cutoff. Nobody at X = 50 is untreated, so it is never observed directly.

To see why centering matters, fit the same lines with raw X. The lines become −60 + 2X and −150 + 4X, so the dummy coefficient is −90: the gap between two lines extrapolated all the way to X = 0, far outside the data. The jump at 50 is still there, but only as β2 + 50β3 = −90 + 100 = 10.

10. A special pile of observations at predictor zero

Among organizations with positive fundraising expense X, donations follow approximately 10 + 4X. Organizations with X = 0 have mean donations of 30. Add a dummy that tests whether the zero cases follow the extrapolated positive-X line. Which value of the line is the comparison?

Short answer

Add dzero = I(X = 0): Y = β0 + β1X + β2dzero + ε gives (10, 4, 20). β2 compares the zero group’s mean (30) with the positive-case line extrapolated to X = 0 (10). It is not a comparison with the average positive organization.

Why this works

  • Zero cases (X = 0, dzero = 1): Y = β0 + β2 = 30
  • Positive cases (dzero = 0): Y = β0 + β1X = 10 + 4X

The zero group gets its own mean through β0 + β2, so the line (β0 and β1) is estimated from the positive cases alone. That is the second benefit of the dummy. Without it, the pile at 30 would drag the intercept up and flatten the slope, misdescribing the organizations that do fundraise. β2 asks whether “zero” behaves like the smallest possible amount of fundraising, or like a different kind of organization. Here it is clearly the second: non-fundraisers raise far more than the line predicts.

11. Zero group and size-specific slopes

The zero-X cases have a distinct mean. Among positive-X cases, large organizations have a different intercept and slope from small ones. Specify the model so each of these three departures is a coefficient. How must size be coded for the zero cases?

Short answer

With small positive-X organizations as the reference, Y = β0 + β1X + β2dzero + β3dlarge + β4(Xdlarge) + ε gives (10, 3, 20, 7, 2). The three departures are β2 (zero group), β3 (large intercept), and β4 (large slope). Code dlarge = 0 for every zero case, so the zero group is a third category rather than a subset of small or large.

Why this works

The model describes three groups, each with its own equation:

  • Zero cases: Y = β0 + β2 = 30
  • Small, positive: Y = β0 + β1X = 10 + 3X
  • Large, positive: Y = (β0 + β3) + (β1 + β4)X = 17 + 5X

This combines exercise 10 (a dummy for the pile at zero) with exercise 4 (intercept and slope shifts for a second group). The coding of size for zero cases matters. If a large zero-expense organization had dlarge = 1, its prediction would be β0 + β2 + β3. Then β3 would have to describe both the gap between the positive lines and a size gap within the zero group, forcing the two to be equal.

If size genuinely matters among zero cases, code it for them and add dzerodlarge, so the zero group can have separate small and large means.

12. COVID anomalies and a later regime

Let dpre mark ordinary pre-COVID years (2014–2019); dcovid20, dcovid21, dcovid22 mark 2020–2022; and dpost marks the stable post-COVID years (2023–2027). Build a model that (a) gives each anomalous year its own deviation and (b) tests whether the later regime is at a new level relative to the pre-COVID trend at the same calendar time. Which category is omitted? Is the dpost coefficient an unadjusted difference in period means?

Short answer

Omit dpre and include a calendar trend t = year − 2014:

Y = β0 + β1t + δ20dcovid20 + δ21dcovid21 + δ22dcovid22 + δPdpost + ε

This gives a trend of 50 + 2t, anomaly deviations (−18, −22, −13), and δP = 9. No, δP is not the raw difference in period means. That raw difference is 26, and 17 of it is just the old trend continuing.

Why this works

Because the trend term is in the model, every dummy coefficient is a vertical distance from the pre-COVID trend line, measured in the same year. Omitting dpre makes the ordinary pre years the reference, so the trend line is estimated from them.

  • Each anomaly year gets its own dummy. One dummy for a single year fits that year exactly, so the three unusual points cannot pull the trend line around. Each δ is that year’s deviation from where the trend would have put it. For 2020, the trend predicts 50 + 2·6 = 62 and the observed value is 44, so δ20 = −18.
  • δP is a shift, not a change in means. In 2023 the trend predicts 50 + 2·9 = 68 and the observed value is 77, a gap of 9. Because the post line is parallel, the gap is 9 in every post year.

Compare that with the naive comparison. The post-period mean (2023–2027) is 81 and the pre-period mean (2014–2019) is 55, a difference of 26. But the trend alone would have raised the mean from 55 to 72 across those years (+17). Only the remaining 9 is a new level.

To test for a temporary disruption, test the three anomaly coefficients jointly: δ20 = δ21 = δ22 = 0 (an F-test). To test for a lasting shift, test δP = 0.

12B. What if the post-COVID slope changed?

In the alternative red post period, the slope is 2 units per year steeper than before. Add one term that tests this change. Define time so that the post-level coefficient is still the vertical gap at the start of the stable post period. What is the post slope?

Short answer

Keep the model from 12 and add tpost = (year − 2023)·dpost, which is zero before 2023 and in 2023 itself. Its coefficient θ = 2 tests the slope change, δP = 9 is still the jump in 2023, and the post slope is β1 + θ = 4.

Why this works

This is the interrupted time series of exercise 8 on top of the anomaly dummies of exercise 12. The post line is

Y = β0 + β1t + δP + θ(year − 2023)

In 2023 the last term vanishes, so the gap from the pretrend there is exactly δP. Each later year adds θ to the gap. Starting the post clock at 2023 is what keeps δP meaning “the jump at the start of the new regime.”

Suppose you used t·dpost instead, with t counted from 2014. The post line would then be (β0 + δP) + (β1 + θ)t, so δP would be the gap extrapolated back to 2014: 9 − 9·2 = −9. The fit is identical, but the sign of the headline coefficient flips.

Test the two components separately, or test δP = θ = 0 jointly to ask whether the post regime differs from the old trend in any way.

13. Reverse-engineer the coding

Group A changes from 50 to 55; B changes from 50 to 70. For each request, choose the group and time references so a single coefficient tests it. You may write a different model for each. (a) B versus A in the pre period; (b) B versus A in the post period; (c) B’s own pre-to-post change; (d) the difference in changes. Are any of these impossible to isolate as one coefficient under a saturated 2 × 2 coding?

Short answer
  • (a) Reference A/pre: the dB coefficient, β1 = 0.
  • (b) Reference A/post: the dB coefficient, γ1 = 15.
  • (c) Reference B/pre: the dpost coefficient, λ2 = 20.
  • (d) Any reference: the interaction, ±15.

None of the four is impossible. What is impossible is getting all four from one model, or getting a diagonal contrast (such as B/post versus A/pre) as a single coefficient under any coding.

Why this works

A saturated 2 × 2 model has an intercept and three coefficients, and every one of them is anchored at the reference cell:

  • the group main effect compares the two groups in the reference period;
  • the period main effect is the change over time for the reference group;
  • the interaction is the difference in changes, which is the same contrast from every reference, up to sign.

So to test a group gap in a particular period, make that period the reference. To test one group’s change, make that group the reference. The diagonal contrast from the reference cell is always the sum of all three coefficients (for example, B/post versus A/pre is β1 + β2 + β3 = 20 in Model 1). No choice of reference makes it a single coefficient, so it needs a linear-combination test.

Every exercise is the same move: choose the reference and the zero point so the contrast you want lands on one coefficient.

What should be clear in my mind?

  1. Name the reference before reading any coefficient. Every dummy coefficient is a gap from the omitted category.
  2. Know where each gap is measured. In a model with an interaction, a dummy coefficient is the gap where the continuous variable equals zero. Center to move that point where you want it.
  3. Recover any cell or line by adding coefficients. Write the equation for each row of the design matrix and solve from the reference outward.
  4. Distinguish imposing from testing. Leaving out an interaction assumes parallel lines; including it lets you test them.
  5. When a contrast is a sum of coefficients, either recode so it becomes one coefficient, or run a linear-combination test.
  6. Never enter a complete set of complementary indicators alongside an intercept.
Instructor note

The diagrams deliberately show conditional means without sampling uncertainty. Have students write the estimand and the model first, then give them an actual dataset to fit the model with standard errors appropriate to its design (clustered for repeated measures, robust for unequal variances, and so on).
