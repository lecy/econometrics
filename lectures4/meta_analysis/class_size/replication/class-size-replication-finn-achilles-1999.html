Research Integrity and Evidence Synthesis

Replicating Shin and Chung: Finn and Achilles (1999)

This is the second replication case study. Finn and Achilles (1999) is a review of Project STAR, not a new experiment. It prints only effect sizes, and its first-grade results come from the same children as case study 1. Shin and Chung (2009) count it as a separate study. This guide shows how to code a paper like this and what happens to a pooled estimate when one experiment is counted many times. The R code is in replication/finn_achilles_1999.R.

Section one

Key concepts

What this second replication adds, stated as claims.

Key concepts

The unit of independence is the sample, not the article.

A meta-analysis assumes each effect size comes from an independent sample. Project STAR produced dozens of articles, reports, and reanalyses of one cohort of Tennessee children. Seven of Shin and Chung’s 17 “studies” include the same first graders.

A review article is a secondary source.

  • This paper’s Table 1 is “taken from Finn (1998),” and its Table 2 is drawn from the Lasting Benefits Study reports.
  • When the same numbers appear in several places, code them once, from the source with the fullest statistics, and record where else they appear.

When a paper prints only d, you still have to build the variance.

You need the sample size in each arm, the contrast, and the clustering. This paper gives none of them directly. Every one has to be borrowed or assumed, and each assumption has to be written down.

Double counting barely moves the mean, but it badly understates the uncertainty.

17 rows treated as 17 experiments → SE 0.007   |   13 rows treated as one cohort → SE 0.040

The pooled effect stays at about 0.22 either way. The standard error is 5.5 times larger once the rows are treated as what they are.

Section four

Step one: check Grade 1 against the 1990 paper

There are no means to recompute from. So check the numbers against another report of the same children.

The Grade 1 column of Table 1 describes the same children, with the same contrast and the same standardizer, as Tables 5 and 6 of Finn and Achilles (1990). The values should be identical.

Most values match, and a few don’t. The race-specific BSF values agree exactly while the overall values differ, so the overall BSF figures were probably computed a different way. One possibility is pooling pupils instead of averaging class percentages. The article doesn’t say.

Two lessons. First, a match on most values is strong evidence that these are the same children, so the 1999 Grade 1 rows are duplicates. Second, reports of one dataset disagree in small ways. When they do, code from the source with the fullest statistics (here, 1990), and note the discrepancy.

Section five

The decision points

Six choices specific to a paper that reports only effect sizes on a sample already coded.

1. Which rows are new information?

Options(a) Code every row in Tables 1 and 2 as a new study, as Shin and Chung effectively did. (b) Code only rows that add children or grades not already coded.

Choice(b). Grade 1 rows are flagged dup_of = finn_achilles_1990 and left out of the primary analysis. Kindergarten, Grade 2, and Grade 3 rows are new measurements, though not new children.

WhyThe Grade 1 values match the 1990 paper (Section four), and the 1990 paper has means and SDs behind them.

2. Mislabeled and mixed outcomes

The trapThe Grade 3 “Reading” value (0.25) is Total Language (footnote b).

ChoiceCode it as total_language, subject = language. A reading analysis then excludes it automatically.

Also“Total Reading” combines Word Study Skills and Reading, so the three reading rows in each grade overlap heavily. Treat them as correlated (decision 6).

3. During treatment vs. after

Options(a) Pool Grades 4–7 with K–3. (b) Code them with timing = after treatment and analyze them separately.

Choice(b). They are coded but not in the primary rows.

WhyThree differences: the question (does the effect persist?), the contrast (small vs. regular), and the SD (pooled in Grades 5–7). Shin and Chung coded this paper as Grades K–3 only, which is consistent with this choice.

4. Building a variance from a total N

ProblemOnly the grade total is printed. The contrast compares small classes with the average of two groups, which changes the variance formula:

v= 1nS + 14nR + 14nA + d22N

ChoiceBorrow the Grade 1 arm shares from the 1990 coding (28.5% small, 38.0% regular, 33.5% aide). Multiply by the same design effect, 2.93, because pupils were still in their experimental classes.

ExampleKindergarten reading, N = 5,738: nS ≈ 1,633, so v = 0.00086, times 2.93 = 0.00252, and SE = 0.050.

Grades 4–7No design effect. The pupils were spread across new classes, so the old class clustering weakened, but by an unknown amount. The SEs there are lower bounds.

5. BSF: a difference without a base rate

Options(a) Guess the regular-class pass rate and convert. (b) Don’t code BSF from this paper.

Choice(b).

WhyThe logit conversion depends on where the gap sits. The same 7.2-point Grade 3 reading gap gives d = 0.16 if 50% of regular pupils pass, 0.21 at 70%, and 0.41 at 85%. A guess that size is worse than a missing value. (Grade 1 BSF is already coded from 1990, with its base rates.)

6. Rows from one cohort are not independent

ProblemAfter duplicates are dropped, 11 primary rows remain from this paper. They are three reading scales and math, measured on overlapping children every year from K to 3.

ChoiceKeep every row with its cohort, grade, and scale. When pooling, use a covariance matrix that assumes r = .7 between tests in the same grade and r = .5 across grades.

WhyThe correlations aren’t reported, so these are assumptions. Exercise 3 varies them. Treating the rows as independent is also an assumption: that r = 0, which is certainly wrong.

Section seven

What double counting does to a pooled estimate

The reading and math rows from both case studies, pooled four ways (Step 7 of the R script).

First, how often do the same children appear in Shin and Chung? Their Table 2 lists eight studies whose data source is STAR. Seven of them include Grade 1:

Study (Shin & Chung, Table 2)GradesSame Grade 1 children?

Nye et al. 19925no, but same cohort (Lasting Benefits)

Now take just the two papers coded so far. Pool their Grade K–3 reading and math rows under four sets of assumptions:

ApproachRowsPooled dSE
A. Every row independent, naive variance170.2240.0072
B. Duplicate Grade 1 rows dropped130.2190.0085
C. + design effect for clustering130.2190.0145
D. + correlation among rows from one cohort130.2180.0397

The estimate barely moves, from 0.224 to 0.218. The standard error grows by a factor of 5.5. Under (A), the 95% CI is 0.21 to 0.24, which suggests near-certainty. Under (D) it is 0.14 to 0.30. That is the honest statement: one very good experiment, not seventeen.

Connect it to Shin and Chung. Their pooled SE is .0104 for 120 effect sizes, even though the effects were strongly heterogeneous (Q = 719.4). Is that the kind of number approach (D) produces, or approach (A)? Their paper mentions dependence only as a “shifting unit of analysis” check. The coding notes report that the pooled effect falls from 0.20 to 0.17 when each study counts once, and to 0.08 when each state counts once.

Section eight

Exercises

Each changes one assumption in finn_achilles_1999.R.

  1. Keep the duplicates. Set in_primary to TRUE for Grade 1 and rerun Step 7 with the 1990 rows removed instead. Does it matter which report of Grade 1 you keep?
  2. The Grade 3 trap. Recode the Grade 3 Total Language row as reading. How much does a reading-only pooled estimate change? Why is the change small here, and when would it be large?
  3. Vary the correlations. Rerun approach D with (rsame, rcross) = (.5, .3) and (.9, .7). How sensitive is the SE?
  4. Persistence. Pool the Grade 4–7 Total Reading and Total Mathematics rows from Table 2. Is the follow-up effect smaller than the K–3 effect? Remember that Grades 5–7 use a pooled SD. Which way would that bias the comparison?
  5. Enrollment or attendance? The 1990 paper says about 22 vs. 15 pupils present, and this paper says median enrollment 24 vs. 15. Which should go in size_L? If effects are later scaled per student removed, how much does the choice change the answer?
