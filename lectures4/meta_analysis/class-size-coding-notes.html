Research Integrity and Evidence Synthesis

Coding Class Size Studies for Meta-Analysis

The last step of the Unit 24 case study. Fifty years of arguing about class size came down to coding decisions: what counts as “class size,” which comparison counts, and how many votes each study gets. This guide turns that history into a coding sheet you can use to pull effect sizes out of class size studies. Read The Class Size Debate first.

Section one

Key concepts

Why a coding template is the right way to finish the class size case, stated as claims.

Key concepts

The class size debate continued because people read the evidence differently, not because the evidence was thin.

By 2009 there were hundreds of estimates. Coleman (1966) found little relationship between school resources and achievement. Glass and Smith (1979) found a consistent benefit of smaller classes. Hanushek (2002) found the econometric estimates inconsistent. Shin and Chung (2009) found about 0.20 SD. Each of these conclusions depends on how the studies were coded.

A meta-analysis is only as good as its coding sheet.

  • A vote count tallies signs. A meta-analysis averages standardized effect sizes and weights them by precision.
  • That average means something only if every effect size measures the same contrast, on the same scale, with the same sign convention.
  • The coding sheet enforces this. Every field is a decision that someone in the debate got wrong or argued about.

Record the class sizes being compared, not just the label on the treatment.

“Small versus regular” could mean 15 versus 23, 1 versus 25, or 25 versus 30. Glass and Smith kept the actual sizes S and L as part of every effect size. Without them you cannot tell a tutoring study from a policy study.

Class size and pupil–teacher ratio are different treatments.

  • Class size = students actually in the room with one teacher.
  • Pupil–teacher ratio (PTR) = enrolled students ÷ teachers at the school or district level. Aides and specialists lower it without shrinking any class.

Every estimate must end up as a d where positive means smaller classes did better.

reported statistic → choose the right SD → scale to a common contrast → fix the sign → d and its variance

Regression slopes on class size are negative when smaller is better. If you forget to flip them, they cancel the positive effects from experiments.

The unit of analysis is a coding choice with a big effect on the answer.

Hanushek counted each estimate as a vote; Krueger counted each study. With the same 59 studies and 277 estimates, they reached opposite conclusions. Shin and Chung’s overall effect is 0.20 when each effect size counts once, 0.17 when each study counts once, and 0.08 when each state counts once.

Section two

The design framework: what a class size study looks like

Before designing a coding sheet, know what the literature typically measures and where the variation comes from.

Why the coding matters for the verdict

The sources on this page all make the same point. The disagreement is mostly about which estimates deserve weight, and that comes down to study features someone had to record:

  • Glass and Smith (1979) coded 725 comparisons from 77 studies, covering about 900,000 pupils over 70 years. Only 60% of those comparisons favored the smaller class, and the average, ignoring which sizes were compared, was about a tenth of an SD. Once they modeled the actual sizes compared, a clear relationship appeared. It was clearest in well-controlled studies where pupils were randomly assigned.
  • Hanushek (2002) argued that estimates from weak designs, like simple cross-sections without controls for family background, should not be treated the same as estimates from value-added models that look only at achievement growth over a limited period.
  • Shin and Chung (2009) used one definition of class size (not PTR) and computed 120 standardized mean differences from 17 U.S. studies. Their random-effects mean was about 0.20 SD in favor of small classes. The effect sizes were strongly heterogeneous (Q = 719.4, df = 119), so the moderators matter.

Six dimensions to design the sheet around

The policy overview in this folder lays out a design framework for coding. Each row below is one dimension. The right-hand column says what the dimension requires of the coder.

DimensionWhat the literature showsWhat it means for coding
Outcomes Standardized reading and math scores dominate. Some studies use writing, science, social studies, ACT/SAT, retention, graduation, or adult earnings. Glass and Smith also included ad hoc tests and teacher ratings. Code subject and test type separately. Math and reading run near 0.20 in Shin and Chung (0.20 and 0.19). Other subjects have too few effect sizes to trust on their own.
Intervention Class size (students per class) is not the same as PTR. Some studies use a binary contrast (small vs. regular), others a continuous count. Record the operational definition and its scale: the sizes compared for binary designs, the unit and range of X for continuous ones.
Magnitude Project STAR reduced K–3 classes from about 22–25 to 13–17 and found roughly 0.20–0.25 SD. The overview adds that small reductions, such as 30 to 25, show negligible effects. Reference point: about 0.20 SD for a reduction of 7–9 students in the early grades. Code the size of the reduction so it can be used as a moderator.
Timing Most outcomes are measured at the end of the year or the next year. STAR gains show up mainly in the first year of small-class exposure and then persist through grade 3. Shin and Chung flag the lack of long-term follow-up as a limitation. Code timing as same-year, next-year, or long-run, plus years of exposure.
Controls Pretests, SES, teacher experience and credentials, school resources, and student demographics. Leaving them out tends to bias the estimates. Code whether each is included, and whether the design is randomized, matched, or uncontrolled.
Context Shin and Chung find larger effects in elementary school than in secondary school (0.20 vs. −0.05). Several syntheses find larger benefits for minority and disadvantaged students. Code grade, subgroup, and state or country. These are the main moderator variables.

Not every source agrees on grade level. The overview credits the finding that effects are strongest in the early grades partly to Glass and Smith (1979). In fact, Glass and Smith found the relationship slightly stronger at the secondary level than the elementary level. The early-grade pattern comes from STAR and from Shin and Chung (2009). So code grade level, and do not assume its direction.

Section three

The coding sheet

One row per effect size, not one row per study. Each field below says what to record and which source showed it matters.

Glass and Smith described the approach in 1979: “A single study might fill several coding sheets”, one for each pair of class sizes, each test, and each age or IQ group reported. That is still the right structure. You code one row per effect size and use a study ID to group rows from the same study. The ID lets you handle dependence later.

FieldWhat to recordWhy it matters (source)
Identification
study_idOne ID per report. Rows from the same report share it. Needed to model within-study dependence. Shin and Chung average about 7 effect sizes per study.

data_sourceThe dataset the estimate comes from, such as STAR, SAGE, Prime Time, or a state administrative file. 8 of Shin and Chung’s 17 studies and 78 of their 120 effect sizes came from STAR. That is dependence between studies (Shin & Chung, 2009).
year, pub_statusPublication year; whether it is a journal article, book, dissertation, report, or conference paper. Published studies averaged 0.21 and unpublished ones 0.15 in Shin and Chung. Glass and Smith also coded the source.
Design
designRCT / matched / repeated measures / cross-sectional / value-added / DiD / fixed effects / RDD / uncontrolled. Glass and Smith found that the assignment method mattered more than any other study feature. Hanushek (2002) doubts estimates without prior achievement. In Shin and Chung, randomized effect sizes averaged 0.20 and nonrandomized ones 0.11.
assign_unitWhat was assigned or compared: students, classes, schools, or districts. Determines which variance formula applies. Clustering in classrooms makes student-level formulas too optimistic.
Treatment
measureClass size or pupil–teacher ratio. Record it exactly as the study defines it. PTR is not class size. Aides and specialists lower PTR without shrinking classes (Shin & Chung, 2009; Hanushek, 2002).
size_S, size_LActual sizes of the smaller and larger classes compared, such as 15 and 23. Glass and Smith treated S and L as part of the effect size itself. Shin and Chung also required exact sizes.
deltaThe size of the reduction, L − S, or the number of students used to rescale a slope. A 0.20 effect from cutting 8 students and one from cutting 2 are different findings.
scaleBinary or continuous. If continuous: the units, the range observed, and whether the model has a squared term. Needed to choose the effect size formula (Section four).
exposureYears in the smaller class. STAR gains are concentrated in the first year (Hanushek, 2002).
Outcome and sample
subject, test_typeReading, math, science, or other; standardized, ad hoc, or teacher rating. Glass and Smith coded both. Shin and Chung found that only reading and math had enough effect sizes to draw conclusions.
gradeGrade level of the students (K–12). Shin and Chung: elementary 0.20, secondary −0.05, grade 10 negative.
subgroupFull sample, or the subgroup reported (minority, low-income, by race, by IQ). Needed to test moderators. Also, estimates from many small subgroups multiply the rows from a study (see Section five).
timingSame-year, next-year, or long-run, with the follow-up length. Most studies are short-term. Shin and Chung flag the lack of long-run data.
Controls
pretestPretest adjustment: ANCOVA, gain score, value-added, or none. Glass and Smith coded this as a form of experimental control. Hanushek treats prior achievement as central.
ses, teacher, schoolWhether the model includes family SES, teacher experience or credentials, and school resources. Leaving them out tends to bias estimates upward (Hanushek, 2002; Shin & Chung, 2009).
Statistics for the effect size
stats_reportedEverything needed to compute d: means, SDs, and n by group; or t/F and df; or b, its SE, and sY; or the SD of change scores and the pre–post r. Reports often leave out means and SDs. Glass and Smith converted t, F, and correlations instead of dropping the study.
sd_typeWhich SD you standardized by: pooled posttest, total Y, within-unit, or change score. The same estimate can give d = 0.10 or 0.20 depending on the SD (Example C).
direction+1 or −1, the sign applied so that positive means smaller classes did better. Hanushek had to correct a reversed sign on four PTR estimates after Krueger found it.
d, var_dThe effect size and its sampling variance. Inputs to the weighted model (Borenstein et al., 2009).
notesFree text: judgment calls, imputed values, and any contact with the authors. Makes the coding reproducible.

Code the analysis model even if you use only part of it. Recording design, controls, and SD type costs little. Leaving them out makes it impossible to test later whether weaker designs produce different effects. That was the central empirical question in the Hanushek–Krueger exchange.

For class size you also need a continuous-dosage row, which the R templates provide. When a study regresses Y on the number of students, the slope is “points per student.” To compare it with an experiment, you scale it up to a realistic reduction and flip the sign.

Example A: an RCT that reports group means and SDs

Reported

Grade 1 students randomly assigned within schools to small classes (15 students; 8 classes, nT = 120) or regular classes (23 students; 6 classes, nC = 138). End-of-year reading scale score: small classes mean 520 (SD 38), regular classes mean 512 (SD 42).

Two lessons from this example. First, the estimate is near STAR’s benchmark, but the interval includes zero. In a vote count this study would be a “no effect.” In a meta-analysis it adds to the precision of the pooled estimate. Second, the variance formula treats all 258 students as independent, but they were taught in 14 classrooms. Note the clustering in the notes field. The true sampling variance is larger than 0.0157.

Example B: an OLS study with a continuous class size slope

Reported

A value-added regression across grade 4 classrooms. Reading score on students per class (observed range 16–30), controlling for prior-year score and free-lunch eligibility. b = −0.9 points per additional student (SE 0.35). SD of reading scores: sY = 40.

This fits template 4 (continuous dosage). A slope of one student is too small to compare with an experiment, so rescale it to a reduction of δ = 8 students, about the size of STAR’s contrast. Because a smaller X is the treatment, use direction = −1:

d = direction × b × δsY =(−1) × (−0.9)(8)40 =(−1)(−0.18) = +0.18

The R template does not compute a variance for this case. Because d is the slope times a constant, the standard error scales the same way:

SEd= δ × SEbsY = 8 × 0.3540 =0.07    v = 0.072 = 0.0049

Things to check before accepting 0.18:

  • The sign. Without the direction flip you would record −0.18, a harmful effect, from a study that found smaller classes did better. If the study had regressed scores on teacher–pupil ratio (teachers per student), the slope would be positive and the direction would be +1. Read the variable definition, not just the sign of the coefficient.
  • The support. An 8-student change (say, 26 to 18) falls inside the observed range of 16–30. Rescaling to a 20-student change would extrapolate beyond the data.
  • The SD. Use the raw SD of Y, not the residual SD from the regression. The raw SD puts the result on the same scale as Example A.
  • Nonlinear specifications. If the model includes class size squared, there is no single slope to rescale. Compute the predicted difference between two specific sizes and code those sizes as size_S and size_L.

This is the same approach Glass and Smith used in 1979 for correlational studies such as Coleman’s. They turned the slope into a comparison between the 25th- and 75th-percentile class sizes and coded those as the “smaller” and “larger” classes.

Example C: a difference-in-differences estimate

Reported

A district cut grade 3 classes from 24 to 17 students; a neighboring district did not. Two years of pre-period and two years of post-period math scores. β3 = 4.0 points (SE 1.5). Reported SDs: the SD of math scores is 40; the SD of student change scores is 20.

Here the choice of SD is the key decision. The R template (template 5) divides by the SD of change scores. The design table divides by the pooled SD of the outcome. They give different answers:

dchange= 4.020 =0.20     dlevels= 4.040 =0.10

They differ because the SD of change scores depends on how strongly scores correlate across time:

schange= s √2(1 − r) =40 √2(1 − 0.875) =40 × 0.5 = 20

So a pre–post correlation of 0.875, which is typical for achievement tests a year apart, cuts the SD in half and doubles the effect size. Nothing about the effect of class size changed. Examples A and B are in units of the SD of achievement levels, so code d = 0.10 (SE 1.5/40 = 0.0375) as the comparable value. Record dchange = 0.20 in the notes, and set sd_type to “pooled levels.”

Code the size of the reduction as it happened: size_S = 17, size_L = 24, delta = 7. Don’t rescale it. A binary policy contrast is not a slope, and scaling it to 8 students (0.10 × 8/7 ≈ 0.11) assumes a linear dose–response. Let a meta-regression on delta test that assumption.

The fixed-effects version of the same problem. Suppose a school fixed-effects panel reports βwithin = −0.6 points per student, with a within-school SD of 25 and a total SD of 40. Template 6 divides by the within-unit SD but has no δ or direction argument. Add both, as in Example B. Scaled to 8 students, the result is (−1)(−0.6 × 8)/25 = 0.192 using the within SD, or 0.6 × 8/40 = 0.12 using the total SD. The within-unit SD is smaller than the pooled SD, so it inflates d relative to an RCT. Code the SD type so the difference can be checked.

Section five

The coding decisions that decide the answer

Each of these has changed a published conclusion about class size. Make each decision explicitly and in writing before you start coding.

1. Pupil–teacher ratio versus class size

PTR is easy to get from administrative data, which is why much of the production-function literature uses it. The estimates Hanushek tabulates are estimates of teacher–pupil ratio effects. Hanushek himself notes that PTR differs from class size because of specialist teachers and how classes are scheduled. He sets the distinction aside because the two move together over time. Shin and Chung made the opposite choice: class size only, because a school with many aides can have a low PTR and large classes. Glass and Smith counted instructors in the room: two teachers with 30 pupils counts as 15.

Decision: Code measure for every row. Then either restrict the sample to class size or keep PTR studies and test measure as a moderator. Do not mix them without recording which is which.

2. Tutoring-level contrasts

Glass and Smith included the whole range from one-on-one tutoring to large lectures. A typical small-group experiment compared individual tutoring with a class of 25 and found about half an SD. Comparisons like that are real, but they measure a different treatment from reducing 23 to 15. Averaged with policy-range comparisons, they raise the mean. Glass and Smith responded to this concern. Dropping the S = 1 comparisons actually made their curve steeper. Dropping all comparisons with S < 6 made it flatter, but it still rose from the 50th percentile at 40 students to the 60th at 10.

Decision: Because you coded size_S and size_L, you can define the policy-relevant range (for example, S ≥ 13) and report the pooled estimate with and without the tutoring-level rows.

3. One estimate, one vote or one study, one vote

This was the center of the Hanushek–Krueger exchange. Hanushek’s summary gives equal weight to each of 277 estimates from 59 studies. Krueger showed that 44% of those estimates came from 15% of the studies. Studies that split their data into many subsamples (by grade, race, subject) contributed many small, imprecise estimates, and those estimates were less likely to be significant. When Krueger weighted each study equally, studies with positive effects were 57% more common than studies with negative ones. Hanushek replied that the study-level weighting favored low-quality estimates.

Both approaches are vote counts. A modern meta-analysis weights by inverse variance, so an imprecise subsample estimate already counts for less. The dependence problem remains, though. Twenty-four estimates from one dataset are not 24 independent pieces of evidence.

Decision: Code every estimate with its study_id. Then report the result under more than one unit of analysis, as Shin and Chung did following Cooper’s “shifting unit of analysis”: effect sizes for subgroup analyses, averaged to the study level for the overall mean.

4. Dependence when STAR dominates

STAR is the best-designed class size study, so it appears everywhere. In Shin and Chung, 8 of 17 studies and 78 of 120 effect sizes come from Tennessee. Those studies are not independent. Many reanalyze the same cohort of children. Changing the unit of analysis showed how much this matters:

Unit of analysisOverall effect (random effects)
Effect size0.20
Study0.17
State0.08

Decision: Code data_source separately from study_id. At a minimum, report the estimate with STAR collapsed to a single unit, and with STAR excluded.

5. Publication status as a moderator

Shin and Chung found larger effects in published studies (0.21) than in unpublished ones (0.15) and read the gap as evidence of publication bias. Hanushek gives a concrete example: Kiesling’s teacher–pupil ratio results appeared in his thesis but were left out of the journal article based on it. Hanushek’s own rule counted only studies published in a book or journal, which is the kind of rule that lets this bias in.

Decision: Search dissertations and reports (Glass and Smith searched Dissertation Abstracts), code pub_status, and test it as a moderator. It connects this unit to the publication bias tools from Unit 23.

6. Sign conventions

“Smaller is better” is written into the effect size. Glass and Smith defined ΔS−L = (X̄S − X̄L)/σ, so positive always means the smaller class did better. Regression studies do not do this. A slope on class size is negative when small classes help. A slope on teacher–pupil ratio is positive. A slope on “reduction in class size” is positive. Hanushek’s own tabulation had reversed the sign on four teacher–pupil ratio estimates from one study until the error was caught in correspondence with Krueger.

Decision: Fix the convention (positive = benefit of smaller classes), code direction explicitly, and have a second coder independently check a random sample of rows, especially the regression-based ones.

Section six

What should be clear in my mind?

What you should be able to do after this page.

  1. The class size debate was a disagreement about coding and weighting, not about whether evidence existed. Glass and Smith, Hanushek, Krueger, and Shin and Chung reached different conclusions from overlapping sets of studies.
  2. The coding sheet has one row per effect size, linked by a study ID and a data-source ID. That structure makes dependence visible and lets you change the unit of analysis.
  3. Always record the actual class sizes compared and the definition used (class size or PTR). The treatment label alone is not enough.
  4. I can convert group means and SDs to Hedges’ g with its variance, and I know the student-level variance understates uncertainty when classrooms are the unit that was treated.
  5. I can convert a class size slope to a dosage d by multiplying by a realistic reduction (8 students), dividing by the SD of Y, and applying direction = −1.
  6. The SD you divide by is a choice that can double the effect size. Change-score and within-unit SDs are smaller than the SD of levels. Pick one scale, use it for every row, and code which SD you used.
  7. Tutoring-level contrasts, PTR studies, STAR reanalyses, and unpublished studies are decisions to make, not noise to average over. Code them so their influence can be tested.
  8. The benchmark to compare against is about 0.20 SD for a reduction of 7–9 students in the early grades. An estimate far from that should prompt a check of the coding before it becomes a finding.

Key takeaways

  • Meta-analysis replaced vote counting, but it only works if every effect size measures the same contrast on the same scale.
  • Glass and Smith’s 1979 coding sheet still holds up: several rows per study, exact sizes S and L, how pupils were assigned, subject, age, and whether there was a pretest.
  • Class size is not PTR. Code which one each study measured.
  • Standardize slopes to a realistic reduction and fix the sign so that positive always means smaller classes did better.
  • Choose the SD deliberately. The same DiD estimate is 0.10 in level SDs and 0.20 in change-score SDs.
  • The unit of analysis moves the answer: 0.20, 0.17, or 0.08 in Shin and Chung depending on whether effect sizes, studies, or states count once.
  • Publication status and study design are moderators to test. Published studies and randomized designs both show larger effects in Shin and Chung.
